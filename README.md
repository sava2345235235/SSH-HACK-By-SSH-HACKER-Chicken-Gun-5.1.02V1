# SSH HACK — Chicken Gun 5.1.02

ESP + Аимбот + Мэджик-пуля. FOV аима 10–100.

| Файл | Что это |

| `SSH-CG-Menu.apk` (103 КБ, также в коде) | Меню поверх игры + ESP-оверлей |

## Установка

### Эмулятор (LDPlayer)
1. Удали оригинальный Чикен Ган (подпись другая, поверх не встанет).
2. Перетащи оба APK в окно эмулятора.
3. Открой меню-приложение, дай «поверх других приложений».
4. Запусти игру, подожди ~15 сек в матче, жми плавающую кнопку **SSH**.

### Телефон
1. Скинь оба APK на телефон (USB / Telegram / Drive).
2. Удали оригинальный Чикен Ган.
3. Установи оба APK (разреши «установку из неизвестных источников»).
4. Открой меню-приложение, выдай «показ поверх других» (Xiaomi: Настройки → Приложения → «Всплывающие окна»).
5. Запусти игру, ~15 сек в матче → кнопка **SSH**.

## Функции
- **ESP** — боксы + линии до врагов
- **Аимбот** — доводка камеры на голову ближнего к центру врага в FOV
- **Мэджик-пуля** — пуля в первые метры полета перенацеливается на ближнего врага (до 60м)
- Слайдер FOV 10–100, плавность

## Техника
`CharacterMotor.myTeam @ 0xEC`, `ProjectileMoveScript.target @ 0x88` (dump.cs).
Либа `libcfjump.so` подхватывается через DT_NEEDED в `libil2cpp.so`, конфиг через `/data/local/tmp/cg_cfg.txt`.
Без рута. Сначала играть на твинке — бан реален.
